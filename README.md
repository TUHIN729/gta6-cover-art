Vice Cover Studio turns any photo and caption into a striking multi-panel, GTA-poster-style cover: three layouts (Vice Grid, Comic Strip, Sunset Duo), per-panel crop and positioning, a Vice City sunset/neon colour grade, bold italic caption lettering on a slanted ribbon, and one-click PNG export in 1080×1080, 1080×1350 or 1920×1080. It runs fully offline in a desktop browser with two built-in demo photos and original procedural skyline art — no Rockstar artwork, logo or font anywhere.

## Run it

```sh
python3 -m http.server --directory app
# then open http://localhost:8000/index.html
# or: npx serve app
# to build /output: node main.ts
```
